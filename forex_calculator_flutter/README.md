# ماشین حساب فارکس (Flutter)

اپلیکیشن فارسی محاسبه حجم معامله بر اساس مدیریت ریسک.

## امکانات
- محاسبه مبلغ ریسک بر اساس موجودی و درصد ریسک
- محاسبه حجم لات بر اساس حد ضرر (پیپ)
- نمایش حجم معادل واحد (Units)
- رابط فارسی و راست‌چین با تم تیره
- ساخت خودکار APK با GitHub Actions

## فرمول
- مبلغ ریسک = موجودی × درصد ریسک ÷ ۱۰۰
- حجم لات = مبلغ ریسک ÷ (حد ضرر به پیپ × ارزش هر پیپ برای یک لات)

ارزش پیپ به جفت‌ارز و ارز حساب بستگی دارد؛ مقدار آن را متناسب با بروکر وارد کنید.

## اجرای محلی
نیازمند Flutter SDK و Android SDK:

```bash
flutter pub get
flutter run
```

ساخت APK:

```bash
flutter build apk --release
```

خروجی محلی:
`build/app/outputs/flutter-apk/app-release.apk`

## ساخت APK در GitHub
1. این پوشه را به‌عنوان یک repository در GitHub آپلود کنید.
2. نام شاخه اصلی را `main` یا `master` بگذارید.
3. وارد تب **Actions** شوید.
4. ورک‌فلو **Build Android APK** به‌صورت خودکار اجرا می‌شود؛ همچنین می‌توانید از گزینه **Run workflow** دستی اجرا کنید.
5. پس از پایان موفقیت‌آمیز، وارد اجرای workflow شوید و از بخش **Artifacts** فایل `forex-calculator-release-apk` را دانلود کنید.

> این نسخه برای محاسبه حجم پوزیشن (Position Size) است و قیمت زنده بازار دریافت نمی‌کند.
